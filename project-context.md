## 3. AUTOMATION & "MAGIC" TOOLS

The repository includes a custom CLI (`scripts/mcp-cli.js`) that performs:

* **`magic:assets`**: The "God Command" that runs the entire asset pipeline.
* **`scrape:lightroom:all`**: A "Headless" fetcher that downloads/optimizes photos from Adobe Lightroom public links.
* **`audit-score`**: A custom telemetry tool that scores the site on Performance (Lighthouse), Accessibility (Pa11y), and Content Integrity.
* **`generate-social-images`**: Auto-generates branded Open Graph images for every page.
