## ⚠️ Needs Configuration

### **GitHub MCP** (5 minutes)
1. Go to: https://github.com/settings/tokens
2. Generate new token (classic) with `repo` scope
3. Open: `C:\Users\hoosi\.cursor\mcp.json`
4. Replace `YOUR_GITHUB_TOKEN_HERE` with your token
5. Restart Cursor

**Full instructions:** `docs/MCP_SETUP_INSTRUCTIONS.md`

### **Brave Search MCP** (5 minutes)
1. Go to: https://brave.com/search/api/
2. Sign up and get API key (free tier available)
3. Open: `C:\Users\hoosi\.cursor\mcp.json`
4. Replace `YOUR_BRAVE_API_KEY_HERE` with your key
5. Restart Cursor

**Full instructions:** `docs/MCP_SETUP_INSTRUCTIONS.md`

### **PostgreSQL MCP** (Optional)
