## 🎨 Background Component Strategy

### **Component Selection Logic**

| Component | Best For | Usage |
|-----------|----------|-------|
| **OceanAuroraBackground** | Hero sections, case study details | Dramatic, flowing gradients |
| **OceanBackgroundBeams** | Content sections, portfolios | Subtle animated beams |
| **OceanGradientAnimation** | Interactive pages, tools | Mouse-responsive blobs |
| **OceanWavyBackground** | About pages, photography | Flowing wave animations |
| **EnhancedOceanBackground** | Global background | Minimal, site-wide base |

### **Opacity Guidelines**

- **20% opacity**: Very subtle, content-heavy pages (Projects, Resume, Gallery)
- **25% opacity**: Medium subtlety (Design, Toolbox, Photography)
- **30% opacity**: More visible, key sections (CareerHighlights, Testimonials)
- **Interactive**: Full visibility with soft-light blending (Applications, Brand Builder)

## 🔧 Technical Implementation

### **Z-Index Strategy**
```css
/* Background layers */
Background Component: z-index: 0 (or absolute positioning)
Content: z-index: 10 (relative positioning)
```

### **Opacity Strategy**
- **Very Subtle (20%)**: Content-heavy pages, long-form content
- **Subtle (25%)**: Medium content density
- **Visible (30%)**: Key sections, hero areas
- **Interactive**: Full visibility with blending modes

### **Component Wrapping Pattern**
```tsx
// Pattern 1: Wrapper Component
<OceanWavyBackground className="page-wrapper">
  <main className="page-content relative z-10">
    {/* Content */}
  </main>
</OceanWavyBackground>

// Pattern 2: Absolute Positioning
<main className="page relative">
  <OceanBackgroundBeams className="opacity-25" />
  <div className="content relative z-10">
    {/* Content */}
  </div>
</main>
```
